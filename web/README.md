# Files for the website root

Generated by `tools/make_llms.tes`, which `build.sh` runs. Do not edit them by
hand; change `harness/reference/tessera.md` or the tool and rebuild.

| File | Served at |
|---|---|
| `llms.txt` | <https://tessera-language.com/llms.txt> |
| `llms-full.txt` | <https://tessera-language.com/llms-full.txt> |

They follow the convention at <https://llmstxt.org>: `llms.txt` is a short index
of what Tessera is and where its documents are, `llms-full.txt` is the whole
language reference in one file. Between them an agent can find and read Tessera
without crawling this repository, and what it reads is exactly the reference the
measurement harness gives a model, so the website and the measurements cannot
drift apart.

The website lives in its own repository,
[dib0/Tessera-website](https://github.com/dib0/Tessera-website). Copy both files
into its public root, or have its build fetch them from here, whenever the
reference changes.
